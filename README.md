Entry for make.fun's **"The Tired Dark Lord: A 100-Word Villain Monologue"**. The program writes one monologue (104 words) to `/output/entry.txt`, spoken by a fantasy villain who is secretly just very tired — the tiredness lives in the rhythm, the chore list and the small deflections, never announced, and the sting lands in the last line: *"I am taking the afternoon off."*

## Run it

```sh
python3 main.py
```

By default the entry is written to `/output/entry.txt`. To write it elsewhere (e.g. for local validation), set `MAKEFUN_OUTPUT`:

```sh
MAKEFUN_OUTPUT=/tmp/entry.txt python3 main.py
```
